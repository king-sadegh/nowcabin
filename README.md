# نوکابین (NoKabin) — سامانه بازسازی تخصصی کابینت بدون تعویض

پلتفرم کامل وب‌سایت، پنل مشتری، پنل اختصاصی مشاورین املاک (با لینک دعوت و محاسبه پورسانت) و پنل مدیریت نوکابین، همراه با دیتابیس SQLite، سیستم ورود با کد یک‌بارمصرف (**OTP در حالت تستی**) و بسته‌بندی کامل **Docker**.

## امکانات کلیدی پیاده‌سازی‌شده
- **صفحه اصلی و مقایسه شفاف هزینه:** نمایش تفاوت یک‌دهم هزینه بازسازی (**۷۰ میلیون تومان**) در مقابل تعویض کامل (**۷۰۰ میلیون تومان**) همراه با محاسبه‌گر هوشمند متراژ.
- **تاکید بر اجرای تخصصی:** رنگ **پلی‌اورتان (غیرکوره‌ای)**، حفظ چیدمان و طرح درب‌ها، و **تحویل در ۱۵ روز کاری** (بدون بخش ضمانت).
- **اسلایدر مقایسه قبل و بعد واقعی:** تصاویر واقعی و مستقیم از روبه‌روی کابینت‌ها بدون تغییر چیدمان یا مدل درب‌ها.
- **صفحه اختصاصی «مشاهده تغییرات واقعی» (`/changes.html`):** گالری پروژه‌های واقعی قبل و بعد با اسلایدر تعاملی و امکان افزودن پروژه‌های جدید از پنل مدیریت.
- **فرم درخواست بازدید و کارشناسی رایگان (`#inspection`):**
  - فیلد «شماره همراه مشاور املاک معرفی‌کننده» با توضیح **۲ میلیون تومان تخفیف** برای مشتریان معرفی‌شده.
  - آپلود عکس کابینت با **محدودیت تعداد عکس برای هر کاربر** (قابل تنظیم از پنل مدیریت، پیش‌فرض ۵ عکس).
- **فرم همکاری با مشاورین املاک (`#agents` - بعد از فرم بازدید رایگان):**
  - انتخاب نحوه ارتباط با **پیام‌رسان بله** یا **واتس‌اپ** با شماره `+989225603574`.
- **مناطق تحت پوشش در فوتر:** اولویت اول **شمال و شرق تهران**، مرکز و غرب تهران و سایر مناطق تهران.
- **پنل‌های سه‌گانه (`/panel.html`) با احراز هویت OTP تستی:**
  - **پنل مشتری:** مشاهده وضعیت درخواست‌ها، تخفیف معرف و مدیریت/آپلود عکس‌ها تا سقف مجاز.
  - **پنل مشاور املاک:** دریافت لینک دعوت اختصاصی (`/?ref=09...`)، مشاهده لیست معرفی‌ها و محاسبه خودکار پورسانت.
  - **پنل مدیریت:** مدیریت درخواست‌ها و تغییر وضعیت/مبلغ قرارداد، تایید مشاورین و تسویه پورسانت‌ها، آپلود نمونه‌کارهای واقعی جدید در گالری، و تنظیم محدودیت آپلود عکس.

## راه‌اندازی روی سرور مجازی ایران با Docker و aaPanel

### ۱. نصب aaPanel روی سرور اوبونتو/دبیان (اختیاری برای مدیریت دامنه و SSL)
به سرور خود با SSH متصل شوید:
```bash
ssh root@YOUR_SERVER_IP
```
> **توصیه امنیتی مهم:** بلافاصله با دستور `passwd` رمز عبور `root` را تغییر دهید.

برای نصب aaPanel:
```bash
URL=https://www.aapanel.com/script/install_6.0_en.sh && if [ -f /usr/bin/curl ];then curl -ksSO "$URL" ;else wget --no-check-certificate -O install_6.0_en.sh "$URL";fi;bash install_6.0_en.sh aapanel
```

### ۲. کلون از GitHub و اجرای سایت با Docker
```bash
git clone https://github.com/king-sadegh/karami.git
cd karami
chmod +x deploy.sh
./deploy.sh
```
اسکریپت `deploy.sh` به‌صورت خودکار Docker را نصب کرده، فایل `.env` را با یک کلید امنیتی تصادفی می‌سازد و کانتینر `nokabin-app` را روی پورت `3000` بالا می‌آورد.

### ۳. اتصال دامنه و SSL در aaPanel
1. در پنل **aaPanel** وارد بخش **Website -> Add Site** شوید و دامنه خود را اضافه کنید.
2. وارد تنظیمات سایت شوید و در بخش **Reverse Proxy -> Add Reverse Proxy**:
   - **Target URL:** `http://127.0.0.1:3000`
3. همچنین می‌توانید از فایل آماده `nginx/nokabin.conf` استفاده کنید و از بخش **SSL** پنل aaPanel گواهی رایگان Let's Encrypt را فعال نمایید.

### ۴. فعال‌سازی دیپلوی خودکار با GitHub Actions
فایل `.github/workflows/deploy.yml` آماده است. برای فعال‌سازی:
1. در مخزن گیت‌هاب وارد **Settings → Secrets and variables → Actions** شوید.
2. با زدن **New repository secret** این سه مقدار را اضافه کنید:
   - `VPS_HOST`: آی‌پی سرور (`87.248.130.21`)
   - `VPS_USER`: نام کاربری (`root`)
   - `VPS_PASSWORD`: رمز عبور جدید سرور
3. از این پس با هر `push` روی شاخه `main`، سرور به‌صورت خودکار آپدیت و ری‌استارت می‌شود.
